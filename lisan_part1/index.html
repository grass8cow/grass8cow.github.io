简单集合论

Cantor-Bernstein 定理：两集合互有单射，则必有双射

对于集合 S,TS,TS,T ，如果存在单射 f:S→Tf:S\rightarrow Tf:S→T 和 g:T→Sg:T\rightarrow Sg:T→S ，则 S,TS,TS,T 之间存在双射。

证明：可以构造一个二分图，左部是 SSS ，右部是 TTT ，那么图是由环和链构成，其中链没有终点，只有起点。

于是对于从 TTT 开始的链，可以令 φ(x)=g−1(x)\varphi(x)=g^{-1}(x)φ(x)=g−1(x) ，否则令 φ(x)=f(x)\varphi(x)=f(x)φ(x)=f(x) 。

环的话就令 φ(x)=f(x)\varphi(x)=f(x)φ(x)=f(x) 即可。

Cantor 定理： 不存在 2S2^S2S 到 SSS 的单射。

假设 φ:2S→S\varphi:2^S\rightarrow Sφ:2S→S 是单射。

令 A=φ(2S)A=\varphi(2^S)A=φ(2S) ，T={x∈A∣x∉φ−1(x)}T=\{x\in A|x\notin \varphi^{-1}(x)\}T={x∈A∣x∈/φ−1(x)} 。

那么 T∈2ST\in 2^ST∈2S 。令 a=φ(T)a=\varphi(T)a=φ(T)

如果 a∈Ta\in Ta∈T ，则 a∉φ−1(a)=Ta\notin \varphi^{-1}(a)=Ta∈/φ−1(a)=T ，矛盾

如果 a∉Ta\notin Ta∈/T ，则 a∈A−Ta\in A-Ta∈A−T ，那么 a∈φ−1(a)=Ta\in \varphi^{-1}(a)=Ta∈φ−1(a)=T ，矛盾

综上，不存在这样的 φ\varphiφ 。
