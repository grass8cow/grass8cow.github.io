Part1 类型与类簇

一些基础类型：Bool, Int …

注意 Int 定长 [−263,263−1][-2^{63},2^{63}-1][−263,263−1] ，而 Integer 不定长

Word 和 Natural 都是无符号整数，但 Word 定长，Natural 不定长

List 类型: 可以看做 []:type->type，[T] 代表一些 T 的元素构成的 list

Tuple 类型：比如 (A,B,C)

注意不存在 1 元 tuple，但1存在 0 元 tuple () 。

=> 一般代表类型类约束 例如 (+) 的类型是 Num a=>a->a->a

一些基础函数：head 是取出 list 第一个元素，tail 是取出第一个元素后余下的元素，last 是取出最后一个元素

一些基础类簇：Eq,Ord,Num

比如 == 的类型是 Eq a=>a->a->Bool ，< 的类型是 Ord a=>a->a->Bool

指这个函数的某个参数或返回值是一个函数。

map：把一个序列中的元素同时进行某种变换

filter：按照一个谓词筛选一些函数

foldr：给定一种运算和一个初始值，在序列上从右往左进行 “累加”

all 表示一个结构中的所有元素是否都满足一个谓词

takeWhile 持续取出一个 list 中的元素，直到遇到第一个不满足指定条件的元素

Part9 代数结构

haskell 中一些常见的代数结构也能作为类型类出现。

半群：Monoid a

定义满足结合律的运算 <> 即可

幺半群：Semigroup a

在半群基础上，定义 empty 表示幺元

在半群上就能定义 fold::Monoid a=>[a]->a ，表示把序列中的元素按半群运算乘起来

我们之前提过的 Foldable 类，其实声明一个 Foldable 的实例就只用定义 fold,foldMap,foldl,foldr，表示你在这个容器上如何“折叠”元素即可
